# 仓库地图与双端联动（中文 / 日本語）

PC 界面复用 AOABLUETOOTH 原项目的 View UI 组件、布局样式、首页卡片和图片资源。地图由你自己画好上传，手机与 PC 读取同一份地图、商品、仓库和信标绑定资料。

## 使用

1. 电脑需要 Python 3.9 或更高版本。Mac 双击 `start.command`；Windows 双击 `start.bat`。保持服务窗口运行。端口被占用时自动选择下一个端口，以窗口显示地址为准。
2. 安装联动版 release APK。签名沿用原项目，可覆盖同签名的旧版，保留本机资料。
3. 手机和电脑连接同一网络，打开手机「仓库地图 · 连接 PC / 联动寻找」，点击「连接 PC / 同步」。填写电脑服务窗口显示的手机服务地址，在 PC「系统设置」复制连接密钥到手机。
4. 首次连接同步手机已有仓库、区域、商品、基站、信标及绑定关系。迁移前的手机资料会保留一份本地备份。
5. PC 选择仓库，上传自己画好的 PNG / JPG 地图（最大 15MB），填写地图名称和楼层。多个仓库、楼层可分别上传。
6. 开启「位置编辑」，选择右侧商品或基站，在图上点击放置；拖动标记调整位置。关闭编辑后浏览和寻找。
7. 手机或 PC 点击寻找，两个地图显示同一商品位置；手机桥接服务调用真实 SDK 发送点灯。任意一端点击停止，提交同一任务的消灯指令。
8. PC 顶部语言下拉栏选择中文或日本語；手机在地图页顶部语言下拉栏切换，返回原生页面时同步应用语言。商品名、仓库名等用户资料保持原文。

## 硬件与状态

- 蓝牙信标使用现有 `XY-FlashFind` SDK：先在手机连接对应基站，保持手机桥接服务运行。退出地图页后仍有前台服务通知。强制停止 App、关闭蓝牙或断网会影响 PC 点灯。
- LAN 信标也通过手机桥接服务，按登记的基站编号连接。基站与手机需要网络可达。
- 此版地图显示你手动配置的位置。实物移动后请调整标记；此版未接入 AOA 实时坐标，也没有把数字信标码猜测转换成 MAC。
- 状态区分等待桥接、正在下发、SDK 已发送、基站已接收、执行失败和已到期。蓝牙 SDK 成功表示指令已发送，实物亮灯需现场核验。LAN F4/F9 回执表示基站确认，不等同于实物 LED 的独立测量。
- 重复寻找会合并；过期任务不执行；桥接中断后，可能已执行的点灯命令不会盲目重发。停止操作可以重试。
- 单次点灯支持 3–381 秒，SDK 时间单位为 3 秒，向上取整；闪烁间隔使用 100ms 单位。
- 同一信标只绑定一个商品。同步冲突时手机保留本地修改，在手机地图连接页点击「冲突处理」选择保留手机修改或采用 PC 资料。

## 保存与备份

地图图片、共享资料、任务和配对密钥保存在 `pc/data/`。重启后保留。完整备份请停止 PC 服务后复制整个 `data` 文件夹；控制台的 JSON 导出不含地图图片。

仅在自己的局域网使用。服务通过连接密钥校验请求，不要把端口直接映射到公网。

./pc/build.sh

node pc/check-ui.cjs

交付包已经包含 `dist`，普通使用无需 Node.js 或前端依赖。开发构建复用 `AOABLUETOOTH/xiyou_web_code/node_modules`。

## 日本語の開始手順

1. PC に Python 3.9 以降を用意し、Mac は `start.command`、Windows は `start.bat` を実行します。
2. release APK をスマホにインストールします。PC と同じネットワークに接続してください。
3. スマホの倉庫マップで PC の LAN URL と接続キーを設定します。キーは PC のシステム設定からコピーできます。
4. PC で倉庫を選択し、作成した PNG / JPG マップをアップロードします。位置編集で商品・基地局を配置します。
5. どちらの端末からでも探索・停止できます。Bluetooth 制御にはスマホ中継サービスと基地局の接続が必要です。
6. 地図上の位置は手動設定です。実物を移動したら配置位置を更新してください。
