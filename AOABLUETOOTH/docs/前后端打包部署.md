# 前后端打包命令

## 1.前端

进入前端目录：

```bash
cd /Users/ichiken/Desktop/projects/AOABLUETOOTH/xiyou_web_code
```

执行打包：

```bash
npm run build
```

打包结果：

```text
xiyou_web_code/dist/
xiyou_web_code/dist-<时间>.zip
```

## 2.后端

进入云端后端目录：

```bash
cd /Users/ichiken/Desktop/projects/AOABLUETOOTH/xiyou-server/xiyou-cloud
```

执行打包：

```bash
./mvnw -s ../../maven-settings.xml clean package -DskipTests
```

打包结果：

```text
xiyou-server/xiyou-cloud/target/xiyou-cloud-0.0.1-SNAPSHOT.jar
```

注意：当前后端代码中的 `QuuppaService.java` 缺少 import，需要修复后才能打包成功。



## 3.替换

将打包文件放进桌面xuniji文件夹，然后进入虚拟机
